# PirrasDev — Portfólio Pessoal

Meu portfólio pessoal, desenvolvido para apresentar minha trajetória na tecnologia, meus conhecimentos, projetos e objetivos profissionais.

O **PirrasDev** reúne um pouco da minha evolução como estudante de Ciência da Computação e do meu interesse pelo desenvolvimento de software, com foco em Backend e Java.

## 🌐 Acesse o projeto

**[Visitar PirrasDev](https://pirraskvcnt.github.io/pirrasdev-my-portfolio/)**

## ✨ Sobre o projeto

O PirrasDev foi desenvolvido com o objetivo de criar um espaço profissional para apresentar minha trajetória, compartilhar projetos e facilitar o contato com outras pessoas da área de tecnologia.

O projeto conta com uma interface responsiva, identidade visual própria e recursos interativos, buscando proporcionar uma experiência simples e agradável em diferentes dispositivos.

## 🚀 Funcionalidades

- **Design responsivo:** adaptação para computadores, tablets e celulares.
- **Tema claro e escuro:** modo dark com detalhes em roxo e modo light com detalhes em verde.
- **Internacionalização:** suporte aos idiomas português e inglês.
- **Sobre mim:** apresentação da minha formação, interesses e objetivos profissionais.
- **Skills:** organização visual dos meus conhecimentos em tecnologias e ferramentas.
- **Projetos em destaque:** apresentação de projetos desenvolvidos e suas respectivas tecnologias.
- **Formulário de contato:** envio de mensagens por meio da integração com Formspree.
- **Links profissionais:** acesso ao GitHub e LinkedIn.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|

## 💻 Executar localmente

Para visualizar ou modificar o código-fonte:

1. Clone o repositório:

```bash
git clone https://github.com/Pirraskvcnt/pirrasdev-my-portfolio.git
```

2. Entre na pasta do projeto:

```bash
cd pirrasdev-my-portfolio
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.
